# 文本拖选闪烁修正

2026-10-04，Windows 11 x64。本轮修正普通文本拖选时系统蓝色与主题灰色交替出现的问题，不修改应用发现、去重或搜索排名。

## 原因与实现

上一版的静态全选/局部选区截图只检查重绘完成后的像素。原生 Edit 在鼠标拖动等选择更新中还会直接向窗口 DC 绘制系统选区；随后子类才触发主题重绘，中间蓝色画面因此可能被显示。

现在在普通选择/编辑消息转交原控件期间标记一次更新。原控件即将绘制而发出 [WM_CTLCOLOREDIT](https://learn.microsoft.com/en-us/windows/win32/controls/wm-ctlcoloredit) 时，仅对 [WindowFromDC](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-windowfromdc) 确认属于该 Edit 的窗口 DC 调用 [IntersectClipRect](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-intersectcliprect)，阻止中间画面写入屏幕。原控件完成文本、选择和滚动更新后，再进行一次已有的缓冲调色与重绘。窗口 DC 由原控件释放，本程序不保存该借用句柄；内存/打印 DC 不裁剪。

嵌套更新由最外层统一重绘，不在窗口调用期间持有 Runtime 可变借用。组字/候选期间使用原生绘制；焦点与输入模式切换保留原流程。不切换可见样式或原控件重绘开关，不改变全局系统颜色。继续复用既有输入框表面，上限 512 KiB，取消选择、组字和隐藏时释放；产品不增加线程、计时器、轮询或磁盘查询。

## 连续屏幕验证

新增 `native_probe.exe --edit-drag`，冻结旧版对照为 `--edit-drag --reference`。独立测试线程持续从屏幕读取本项目 Edit 的像素；使用真实左键按下、逐字移动、释放，期间采样，不以拖动结束截图替代。每次移动确认前台和命中窗口；边缘拖出 Edit 时确认捕获仍属于本控件，异常时释放鼠标并终止。只有测试探针增加采样线程。

两版各启动亮/暗主题两个新进程，每个进程覆盖诊断 DPI 96/120/168/192。每档包含中文/英文混合查询的正向和反向拖选，以及 400 字符的边缘水平滚动拖选，共每版 24 次。步间等待 12 ms，开始前等待消息屏障；未做专门预热拖动。文件/系统缓存自然预热，未模拟冷磁盘或低配机器。入口来源为空测试目录，图标关闭，临时英文模式关闭；不打开用户应用。

| 连续采样 | 修复前 | 最终修复版 |
| --- | ---: | ---: |
| 拖选次数 | 24 | 24 |
| 屏幕采样帧数 | 1,560 | 1,553 |

最终版 172 项断言通过：检查主题选区实际显示、未检出系统蓝色、原生选区端点、文本未改变、键入替换、水平滚动后首字符坐标移出左边缘、鼠标捕获释放、控件保持可见、选区表面预算及隐藏释放。96/120/168/192 DPI 的表面仍分别为 68,608 / 107,200 / 210,112 / 274,432 字节。

这是连续 GDI 屏幕采样，不能覆盖任意短于采样间隔的画面或代替其他系统上的验证；结果表示本机这些路径未再观察到蓝灰交替。

## 回归

- `cargo test --offline`：29 项单元测试与 5 项搜索流程测试通过。
- `cargo fmt --check`、`cargo clippy --offline --all-targets -- -D warnings`、`cargo build --release --offline` 通过。
- `--appearance`：153 项通过，保留查询、稳定位置、主题像素与表面释放通过。
- `--ime-real`：109 项通过，实际 Rime 英文输入、中文提交、Enter/Escape 和受控启动通过。
- `--input-session`：82 项通过，原中文/英文状态在隐藏、失焦、受控启动、关闭开关和正常退出后恢复，回到原测试窗口实际输入验证通过。
- `--flicker`：9,888 项通过，首次上下键、局部两行重绘、图标开关、DPI 和隐藏资源释放通过。

上述最终回归均正常退出码 0。中间方案曾出现可见标记观测冲突，后来弃用重绘开关；探针全长选区的边界错误也已修正。一次输入状态断言失败后撤回额外焦点绘制改动，随后还有一次前台切换打断，均未计入最终成功记录。最终回归保留原焦点路径并完整通过。原始 CSV、对照版本、最终 stdout/stderr 和退出码保留在忽略目录 `runtime/probe-edit-drag/`，最终输出文件以 `final-` 开头。
