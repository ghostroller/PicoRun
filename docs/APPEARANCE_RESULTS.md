# 呼出位置与文本选区验证

2026-10-04，Windows 11 x64。本次修改接续查询保留功能，不修改应用发现或去重规则。

## 结果

原呼出位置为 `工作区顶部 + (工作区高度 - 当前面板高度) / 3`，查询改变条数后会改变输入框位置。现在以当前 DPI 下最多 12 条结果的面板高度定位，结果减少时只缩短下边缘；水平仍居中于呼出时前台窗口所在屏幕的工作区。参考面板比工作区高时，顶部取工作区顶部。移到其他 DPI 的屏幕时，若同步 DPI 通知替换 renderer，再用更新后的 DPI 定位一次。

真实窗口覆盖亮/暗主题和诊断 DPI 96/120/168/192，每档的 0/1/12 条结果均保持相同输入框位置。例如本次 168 DPI 下，面板高度从 998 变为 272 像素，输入框顶部仍为 380 像素。

文本选区分别采用暗色 `#3F4249` 和亮色 `#DCDFE4`，文字采用本主题前景色。原生 Edit 继续负责选择、编辑、滚动、剪贴板、光标与输入法；普通选区使用原控件的 [WM_PRINTCLIENT](https://learn.microsoft.com/en-us/windows/win32/gdi/wm-printclient) 绘制后在本地 DIB 表面调色，保留原生文字布局和抗锯齿覆盖。通过 [GdiFlush](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-gdiflush) 同步后读取 [DIB 像素](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createdibsection)，不改变全局系统颜色。

表面只覆盖输入框，上限 512 KiB，重绘时复用；取消选择、开始组字和隐藏时释放。96/120/168/192 DPI 的实际表面分别为 68,608 / 107,200 / 210,112 / 274,432 字节。组字/候选、超预算或资源不足时采用原生绘制，不新增线程、轮询或查询磁盘 I/O。

## 验收

- `cargo test --offline`：29 项单元测试与 5 项搜索流程测试通过。新增测试覆盖不同结果数量/屏幕原点、选区像素调色和表面预算。
- `cargo fmt --check`、`cargo clippy --offline --all-targets -- -D warnings`、`cargo build --release --offline` 通过。
- `native_probe.exe --appearance --bench`：153 项功能断言通过，正常退出码 0。检查固定位置、仍按结果缩放高度、查询保留全选、屏幕上全选/局部选中的主题像素、键入替换、1024 单位长文本、表面释放及系统颜色前后相同。两个主题、四档 DPI 的静态选区采样均未检出系统蓝色背景像素。此项只覆盖绘制完成后的画面，漏掉了拖动中先蓝后灰的中间帧；后续修正与连续采样见 [EDIT_DRAG_RESULTS.md](EDIT_DRAG_RESULTS.md)。
- `native_probe.exe --ime-real`：109 项通过，正常退出码 0。实际 Rime 英文替换、中文提交、Enter 防重复与取消后再次呼出通过；受控快捷方式启动、剪贴板、查询保留、主题和单实例回归通过。
- `native_probe.exe --input-session`：82 项通过，正常退出码 0。原输入框中文/英文状态、呼出、Esc/热键/失焦/受控启动、关闭选项与正常退出后的恢复均通过，返回原窗口实际键入确认。
- `native_probe.exe --flicker`：9,888 项通过，正常退出码 0。亮暗主题、图标开关、首次上下键、无结果重开、DPI、两行局部绘制及隐藏释放行缓冲通过。

早期一次出现预期外 `f` 输入，随后两次受 Windows 前台激活限制打断，均未计入成功或性能统计；最终探针使用已注册的专用测试热键取得前台权限，并在性能采样中检查前台和查询。失败输出与最终证据保留在忽略目录 `runtime/probe-appearance/`，完整回归另见 `runtime/probe-controlled/`、`runtime/probe-input-session/` 和 `runtime/flicker/probe-fixed/`。

## 完整进程成本

机器：i7-11700K，8 核/16 线程，32 GiB RAM，Windows 11 Enterprise build 26200，x64；未绑单核或模拟低配/换页。Rust 1.95.0 / MSVC，静态 CRT，release opt-level 3、fat LTO、1 codegen unit、panic abort、strip。

基线是本会话开始冻结的查询保留版本，SHA256 `608D3180A2A57B4942B4B239E2DB3DB381CBEFBCBC721650BF826241B27B7DCB`；新版本为 `7955AB4A9C041A29C6CA520B60B896E9B8B4F4924BDAC0DD5F306FCB05C97AB9`，771,584 字节。两版各 5 个新进程，按轮次交替先后顺序；500 个受控入口、图标关闭、临时英文模式开启、实际 DPI 168。系统文件/页面缓存已预热，未做冷磁盘启动实验；初始隐藏采样保留每个新进程的启动状态。

每进程查询 `synthetic` 后先呼出 20 次预热，再采 120 次，共每版 600 次。计时只含同步呼出消息及 `UpdateWindow` 返回，隐藏操作在计时外；包含焦点/英文模式切换及原生绘制，不是搜索核心或物理按键到屏幕呈现延迟。P50/P95 使用最近秩，时间按每版全部 600 次合并，内存按 5 个进程各阶段快照统计。

合并时间 P50 增加约 3.39 ms，P95 相近；每进程波动较大，不能把差额全部归因于选区绘制或宣称呼出提速。两版每个进程最终 1 秒空闲采样 CPU 增量相同，前三轮为 15.625 ms、后两轮为 0；不据此宣称绝对零空闲 CPU，产品仍使用阻塞消息循环。

## 范围

本轮未改变搜索核心，既有 500/2000/10000 项搜索测试和基准口径独立。Windows 10、32 位、其他输入法、极低配/换页实机、真正切换混合 DPI 屏幕仍待验证。极小工作区若无法容纳 12 行，底部容纳问题仍需单独处理；本轮确保输入框顶部不因查询改变。

新版本已恢复原启动参数、查询和隐藏状态，用户主题、图标、英文模式与自启动设置保持原值。
