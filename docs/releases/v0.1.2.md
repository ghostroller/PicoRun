# PicoRun v0.1.2

修复已安装 ChatGPT、Microsoft Store 等商店应用无法搜索到的问题。

- 默认来源新增当前用户已安装的打包应用，通过 Windows AppsFolder 原生枚举；启动和 F5 刷新时更新，搜索时不扫描。
- 使用 Windows 提供的本地化应用名称，支持中文名称、拼音全拼、首字母和中英混合查询；按应用激活 ID（AUMID）去重。
- 打包应用接入 Windows 原生激活接口；普通快捷方式继续通过原入口打开。开启图标时，打包应用暂用通用图标。
- 缓存增加 AUMID 入口，并兼容读取旧版缓存；来源读取失败时保留此前可用的入口。
- 显式 `--source` 仍只读取指定文件夹。没有新增 Rust 依赖、常驻线程或后台轮询。

59 项 Rust 测试（54 项单元测试、5 项集成测试）、格式检查、Clippy 和 release 构建通过。Windows 10 22H2（19045）x64 的三轮真实窗口验证均找到 ChatGPT 和 Microsoft Store，手动刷新、缓存重读和正常退出通过；本机索引包含 22 个打包应用、共 330 个入口。成功的打包应用启动尚未验证，本轮没有打开个人应用。快捷方式探针完成 15 项受控断言后在本机 Shell DLL 中发生原生异常，不能将其完整退出记为通过。详见 [商店应用验证报告](https://github.com/ghostroller/PicoRun/blob/v0.1.2/docs/STORE_APPS_RESULTS.md)。

完整进程测量中，初始隐藏私有提交中位数约 4.97 MiB，比旧版增加约 1.03 MiB；工作集和扫描耗时也有增加。搜索、真实窗口响应和完整进程内存分别测量，口径与局限见报告，不代表低配实机性能承诺。其他 Windows 10 版本、32 位、ARM64 和低配实机尚未验证。

升级前从托盘退出旧版 PicoRun，再运行 Windows x64 安装包，或解压 ZIP 后运行 `picorun.exe`。`SHA256SUMS.txt` 记录两个包的校验和；`build.json` 记录构建工具链、源码标签与提交。项目整体许可证尚未选定，附带 MIT 许可适用于拼音数据。
