# PicoRun v0.1.3

补齐应用发现，修复图标缩放和从终端启动后的应用生命周期问题。

- 商店应用显示真实图标；普通和商店应用图标按当前 DPI 的实际显示尺寸提取，减少多余缩放。小尺寸细节仍受原素材和系统缩放限制。
- 默认扫描新增 HKCU／HKLM App Paths 的 32／64 位视图，并扩展到开始菜单根目录，排除 Startup 子树；支持 ClickOnce `.appref-ms` 入口。显式 `--source` 继续只扫描指定目录。
- 快捷方式使用 Windows 本地化名称，并为原快捷方式名和目标程序名生成有界搜索别名，支持中文、拼音全拼、首字母和中英混合查询。
- 修复从终端或 `cargo run` 启动后，关闭终端会连带终止已打开应用的问题。隔离启动保留原 `.lnk` 参数、工作目录和 App Paths 的私有 PATH；无法独立启动时明确报告错误。
- 缓存升级为 v3，兼容读取 v1／v2；来源读取失败时保留此前可用入口。没有新增 Rust 依赖或后台轮询。

107 项 Rust 测试、格式检查、Clippy，以及 release／debug 构建通过。Windows 10 22H2（19045）x64 上完成原生窗口、来源刷新和缓存、受控应用启动，以及终端关闭后的生命周期验证。验证针对本地构建，详见 [图标尺寸报告](https://github.com/ghostroller/PicoRun/blob/v0.1.3/docs/DPI_ICONS_RESULTS.md)、[应用来源报告](https://github.com/ghostroller/PicoRun/blob/v0.1.3/docs/DISCOVERY_SOURCES_RESULTS.md)和[启动生命周期报告](https://github.com/ghostroller/PicoRun/blob/v0.1.3/docs/LAUNCH_LIFETIME_RESULTS.md)。

完整 Windows 10 兼容性、低配实机、32 位和 ARM64 尚未验证；上述结果不代表低配性能承诺。
