# PicoRun v0.1.1

修复 Windows 启动、应用发现和分发验证中的七项问题。

- 修复图标工作线程停止时可能丢失唤醒，导致退出卡住的问题。
- 已知应用来源暂时离线时，保留该来源此前发现的入口。
- 使用 UTF-16 路径键，避免 Unicode 小写转换误合并不同应用路径。
- 第二实例等待首个实例完成初始化，再呼出已有窗口；启动失败或超时给出错误。
- 第二实例向已有窗口转交前台权限；系统拒绝激活时给出点击输入框的提示，并保留输入模式。
- 卸载器支持正常 UNC 安装路径的自启动归属判断，保留其他副本的注册项。
- 包验证启动失败时清理自身测试进程，避免遗留子进程。

应用支持中文名称、拼音全拼、首字母和中英混合查询。没有新增运行时依赖。

验证包括 47 项 Rust 测试、14 项双进程启动与焦点断言、106 项原生窗口断言，以及新版安装、升级、卸载和 ZIP 的 53 项隔离生命周期验证。格式检查、Clippy 和 release 构建通过。详见 [修复验证报告](https://github.com/ghostroller/PicoRun/blob/v0.1.1/docs/REVIEW_FIXES_RESULTS.md)。

验证环境为 Windows 11 x64；目标仍为 Windows 10 及更新版本。Windows 10、32 位、ARM64 和低配实机尚未验证。

下载 Windows x64 安装包，或解压 ZIP 后运行 `picorun.exe`。`SHA256SUMS.txt` 记录两个包的校验和；`build.json` 记录构建工具链、源码标签与提交。项目整体许可证尚未选定，附带 MIT 许可适用于拼音数据。
