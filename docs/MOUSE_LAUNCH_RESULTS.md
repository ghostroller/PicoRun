# 2026-10-04 鼠标打开应用验证

鼠标左键点击其他结果行先选中，点击已选中的行打开应用。键盘或默认选中的首行也可直接点击打开；连续点击其他行可先选中再打开。点击在 `WM_LBUTTONDOWN` 处理，窗口类未启用单独的双击消息。

打开复用 Enter 的 `activate()`：同步真实 Edit 文本，执行原 `.lnk`，隐藏窗口并恢复原输入模式；启动失败沿用可恢复的状态提示。选择继续只使旧、新两行失效。没有新增常驻缓存、后台线程、计时器或依赖。

命中范围与 renderer 的 DPI 几何一致，排除左右边距、输入框上方、页脚和空结果。组字或候选窗口活跃时不打开；隐藏后排队的点击不再次打开。若点击时同步尚未处理的文本变化替换了结果，本次只选中更新后的行，再次点击才打开，避免执行旧候选。

## 本轮证据

- Windows 11 x64，Rust 1.95.0，MSVC/static CRT；release 使用 opt-level=3、fat LTO、单 codegen unit、panic=abort、strip。
- `native_probe.exe --mouse` 通过 279 项断言：亮/暗主题 × 图标关闭/开启 × 96/120/144/192 DPI 布局，共 16 个组合、4 个原生进程，全部正常退出。
- 实际鼠标按键验证在本机 168 DPI（175%）的原生窗口通过：先选中第二行不打开，再点击该行打开受控程序。注入前核对前台和点击位置属于自己的测试窗口，操作后恢复鼠标位置。
- DPI 组合通过进程内诊断触发 `WM_DPICHANGED` 检验布局；不代表在四档显示设置或四台机器上实测。其他边界通过真实窗口的鼠标消息验证，IME 场景使用注入的组字/候选通知。
- 检查覆盖默认/键盘选择、边距与页脚、无结果、隐藏后的重复点击、IME 关闭后的打开、快速输入后点击，以及原快捷方式的中文/空格参数和工作目录。只打开受控程序。
- 26 项单元测试和 5 项搜索/控制器集成测试通过；`cargo fmt --check`、`cargo clippy --offline --all-targets -- -D warnings` 和 `cargo build --release --offline` 通过。
- 原有 `native_probe.exe` 完整原生窗口回归通过 68 项检查，exit=0；覆盖 Enter、IME 按键、托盘与主题、Delete/粘贴、快捷方式启动、刷新、热键冲突、单实例和重启保存。证据在 `runtime/probe-controlled/checks.txt`。
